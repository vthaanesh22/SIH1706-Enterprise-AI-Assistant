# Intelligent Enterprise Assistant – SIH1706

## Problem Statement
Develop an AI-powered chatbot that can assist employees of a large public sector organization. The chatbot should answer queries related to HR policies, IT support, and company events. It should also analyze uploaded documents to summarize them or extract key information.

## Proposed Solution
We propose an Intelligent Enterprise Assistant using Natural Language Processing (NLP) and Deep Learning. The chatbot will understand employee queries and provide accurate responses using a knowledge base built from HR and IT documents.

## Key Features
- AI chatbot for HR and IT queries
- Document summarization
- Keyword extraction
- Email OTP authentication (2FA)
- Bad language filtering
- Multi-user support
- Response time under 5 seconds

## Technology Stack
Frontend:
- React.js / HTML CSS

Backend:
- Python (FastAPI)

AI/NLP:
- LangChain
- Transformers
- Sentence Transformers

Database:
- PostgreSQL
- FAISS Vector Database

## System Architecture
User → Authentication → Chatbot Interface → NLP Engine → Knowledge Base → Response

## Future Improvements
- Voice-based chatbot
- Multi-language support
- Integration with enterprise systems
